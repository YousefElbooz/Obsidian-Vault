# The #Prompt #WorkFlow

| **Tool / Framework**    | **Role in Your Workflow** | **Best Used For**                                                                                                                         |
| ----------------------- | ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Spec Kit**            | The Shared Brain          | Generating the `spec.md` and `tasks.md` files. It acts as the definitive blueprint and prevents the AI from forgetting the project rules. |
| **UI UX Pro Max (MCP)** | The Design System         | Querying professional design rules to generate a master design document so the AI doesn't create generic, ugly UI.                        |
| **OpenCode (Terminal)** | The Architect             | Running the Spec Kit commands (`/specify`, `/plan`), researching, and generating the architectural plans before any code is written.      |
| **Antigravity (IDE)**   | The Executor              | Using the Agent Manager to read the tasks and write the actual code across your React components simultaneously.                          |
| **Gemini Pro (Web)**    | The Brainstormer          | Deep debugging, brainstorming architecture, or manually writing complex logic when API rate limits are tight.                             |
